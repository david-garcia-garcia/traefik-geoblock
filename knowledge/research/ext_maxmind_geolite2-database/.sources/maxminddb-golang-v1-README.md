Go reader for the MaxMind DB format. Can read GeoLite2 and GeoIP2. `geoip2` (oschwald/geoip2-golang) is the higher-level API.

“This is not an official MaxMind API.”

Install: `go get github.com/oschwald/maxminddb-golang`. ISC license.
