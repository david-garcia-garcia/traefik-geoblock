License keys authorize web-service queries and GeoIP/GeoLite database downloads. A key is tied to the account; treat it as a password. Anyone with the key can consume the account’s download limit or service credit.

Automating downloads or querying web services requires both a license key and the account ID. Up to 100 active keys. After the first key, at least one key must remain active. Full key is shown only at generation (stored hashed).
