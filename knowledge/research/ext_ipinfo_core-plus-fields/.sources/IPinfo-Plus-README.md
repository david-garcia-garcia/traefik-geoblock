Schema table matches the official Plus field names (including dma/geoname/radius, carrier, change dates, privacy flags). Sample files limited to 100 rows.

`as_name` / `as_domain` descriptions are swapped versus the official Plus product page (same swap as Database Types and the Core sample README).

Filename table documents `ipinfo_plus.*` slugs, matching the official Plus product page. On-disk samples: `ipinfo_plus_sample.{csv,json,mmdb,parquet}`.
