Filename reference for CSV, JSON, MMDB, Parquet. CSV and JSON are gzip-compressed.

Sample datasets: updated daily, 100 rows, identical data across formats for the same product. Official statement: sample datasets can be downloaded without an IPinfo access token. Intended for testing and integration.

Page has IPinfo Lite / Core / Plus headings; per-product URI tables were not present in the fetched HTML (likely client-rendered). Full Core/Plus URLs are owned by the Core and Plus database pages.
