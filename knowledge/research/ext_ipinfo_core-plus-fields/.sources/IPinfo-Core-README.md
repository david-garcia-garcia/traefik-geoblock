Schema table matches the official Core field names. Sample files limited to 100 rows.

This README’s `as_name` / `as_domain` descriptions are swapped versus the official Core product page (`as_name` labeled “Organization domain name of the ASN”).

Filename table still documents `ipinfo_standard.{csv.gz,mmdb,json.gz,parquet}` curl URLs. Sample links in the README point at `ipinfo_standard_sample.*`. On-disk files in this folder are named `ipinfo_core_sample.{csv,json,mmdb,parquet}`. Official Core product page uses `ipinfo_core.*`.
