Three bundle databases:

- IPinfo Lite (Country, ASN): free download, CC-BY-SA 4.0.
- IPinfo Core (Location, ASN, Network Flags): geolocation, ASN, and network flags (VPN, anycast, carrier, satellite, hosting).
- IPinfo Plus (Comprehensive IP Database): geolocation with stability insights, detailed privacy, ASN, and network flags.

Comparison table lists these field names (examples in parentheses): `network` (176.53.177.43), `city` (London), `region` (England), `region_code` (ENG), `country` (United Kingdom), `country_code` (GB), `continent` (Europe), `continent_code` (EU), `latitude`, `longitude`, `timezone`, `postal_code`, `dma_code`, `geoname_id`, `radius`, `asn` (AS212238), `as_name` (Datacamp Limited), `as_domain` (datacamp.co.uk), `as_type` (hosting), `carrier_name`, `mcc`, `mnc`, `as_changed`, `geo_changed`, `is_anonymous`, `is_anycast`, `is_hosting`, `is_mobile`, `is_satellite`, `is_proxy`, `is_relay`, `is_tor`, `is_vpn`, `privacy_name` (NordVPN).

On this page, `as_name` is described as “Organization domain name of the ASN” and `as_domain` as “Name of the ASN organization” — swapped relative to the Core and Plus product pages. Per-product checkmarks in the comparison table did not appear in the fetched text.

No `isp` field name on this page. Paid “Standard” and “Extended” databases are listed separately from the three bundles.
