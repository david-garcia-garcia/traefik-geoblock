`ipinfo download` downloads free IPinfo databases and verifies SHA256. Documented database names: `asn`, `country`, `country-asn`. Flags: `--token`, `--format` (`mmdb`, `csv`, `json`).

`ipinfo mmdb read` reads MMDB data for IPs / ranges / CIDRs. This CLI download list does not name the `ipinfo_lite.*` slugs used on the Lite database page.
