Official sample repo for IPinfo database products. IPinfo Lite sample lives in `/IPinfo Lite`. Products listed as available in CSV, JSON, Parquet, and MMDB.

Lite description: location (country + continent) and ASN in one database. Field table matches the official Lite database page (network, country, country_code, continent, continent_code, asn, as_name, as_domain).

Each product folder: ~100-row samples, API response JSON, field breakdown. Core sample schema includes city and region (not on Lite).
