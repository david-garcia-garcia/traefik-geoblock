Version **v1.5**. Install: `cscli parsers install crowdsecurity/traefik-logs`.

Description: parser supports access logs in Common Log Format (defined for Traefik) and JSON formats.

Collection `crowdsecurity/traefik` notes: traefik parser supports CLF and JSON; example acquisition uses `type: traefik` on log filenames.
