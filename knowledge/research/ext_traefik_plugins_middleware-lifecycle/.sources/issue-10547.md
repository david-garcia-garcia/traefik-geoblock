Open issue `area/plugins` / `kind/enhancement` (as of fetch).

juliens (Traefik staff, 2024-07-02): In a Yaegi plugin, use the `context` received by `New`. That context is `Done()` when a new dynamic configuration is deployed and so before a new `New` middleware is created. Kept open because context is not working on WASM.

juliens later pointed at commit `fadee5e87b2cb52855977b42d1590acc9044d65d` as introducing the cancel.

A later comment claimed v2.11.7 does not cancel. That claim is comment-rank; not re-verified here.

The original report: a plugin that starts a goroutine in `New` has no documented way to know the instance is gone; Traefik has no `close()` on middleware plugins.
